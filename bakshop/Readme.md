# BakShop — магазин автозапчастей

Сайт магазина автозапчастей на Django. Красно-белый дизайн, каталог товаров с фото и ценами, поиск, регистрация покупателей и панель управления товарами для администратора.

## Возможности

- Главная страница с карточками товаров (фото, бренд, название, марка авто, цена)
- Поиск по названию, бренду и марке авто
- Регистрация, вход и выход покупателей
- Панель администратора на сайте (`/panel/`): добавление, изменение и удаление товаров
- Встроенная админка Django (`/admin/`)
- Загрузка фото с ограничением 3 МБ и автоматическим уменьшением до 800 px
- Подвал с контактами, адресом и часами работы
- Адаптивная вёрстка для телефонов

## Технологии

- Python 3.14
- Django 6.1
- Pillow (работа с фото)
- HTML и CSS (без сторонних библиотек)
- SQLite (база данных по умолчанию)

## Установка и запуск

Команды для Windows (PowerShell).

1. Перейди в папку с проектом:
   ```
   cd путь\к\BAKSHOP
   ```

2. Создай и включи виртуальное окружение (если его ещё нет):
   ```
   python -m venv venv
   venv\Scripts\activate
   ```

3. Установи зависимости:
   ```
   pip install django pillow
   ```

4. Перейди в папку с `manage.py` и подготовь базу данных:
   ```
   cd bakshop
   python manage.py makemigrations
   python manage.py migrate
   ```

5. Создай администратора:
   ```
   python manage.py createsuperuser
   ```
   Пароль при вводе не отображается, это нормально.

6. Запусти сервер:
   ```
   python manage.py runserver
   ```

7. Открой в браузере `http://127.0.0.1:8000/`

## Основные адреса

| Адрес | Что это |
|---|---|
| `/` | Главная, каталог и поиск |
| `/accounts/login/` | Вход |
| `/accounts/register/` | Регистрация |
| `/panel/` | Список товаров для администратора |
| `/panel/add/` | Добавить товар |
| `/panel/<id>/edit/` | Изменить товар |
| `/panel/<id>/delete/` | Удалить товар |
| `/admin/` | Админка Django |

Панель `/panel/` открывается только пользователям с правами сотрудника (`is_staff`). Аккаунт, созданный через `createsuperuser`, такие права имеет.

## Как добавить товар

1. Войди под аккаунтом администратора.
2. Открой меню с твоим именем в шапке и выбери «Панель товаров».
3. Нажми «+ Добавить товар».
4. Заполни поля, выбери фото (до 3 МБ) и нажми «Сохранить».

Метка в поле «Метка» (например, «Хит» или «-15%») отображается на фото карточки. Товары, отмеченные как «нет в наличии», на главной не показываются.

## Как изменить контакты и адрес

Контакты находятся в подвале сайта. Открой `main/templates/main/base.html`, найди блок `<footer>` и поменяй телефон, email, адрес и часы работы.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| `TemplateDoesNotExist` | Проверь путь в `{% extends "main/base.html" %}` и что папка `templates` лежит внутри приложения `main` |
| Стили не применяются | Нажми Ctrl+F5, проверь `STATICFILES_DIRS` в `settings.py` и строку `{% static 'css/main_style.css' %}` |
| Фото не загружается | Проверь `enctype="multipart/form-data"` в форме, установлен ли Pillow, настроены ли `MEDIA_URL` и `MEDIA_ROOT` |
| `No module named PIL` | Выполни `pip install pillow` |
| `/panel/` перекидывает на вход | Войди под аккаунтом администратора |
| `CSRF verification failed` | В форме с методом `post` нет `{% csrf_token %}` |

## Перед публикацией в интернет

- Поставить `DEBUG = False` в `settings.py`
- Указать домен в `ALLOWED_HOSTS`
- Вынести `SECRET_KEY` из кода в переменные окружения
- Настроить раздачу статики и загруженных фото через веб-сервер
- Заменить контакты в подвале на настоящие
